# Обратная сторона — журнал и витрина

Основной репозиторий большого сайта: https://github.com/Nikiau12/obratnaya-storona-2

Это отдельный проект от сайта-визитки `Nikiau12/obratnaya-storona`.
Исходники, изображения, шрифты, контент, тесты и история изменений хранятся здесь.
Для разработки и сборки не нужен ChatGPT или плагин Sites.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm ci
npm run dev
```

## Сборка и проверки

```bash
npm run check
npm run start
```

`npm run check` проверяет TypeScript, ESLint, сборку и тесты. `npm run start` запускает собранное приложение локально.
Стек: React, TypeScript, Next.js API / vinext, Vite, Cloudflare Workers.

Для проверки интерфейса запустить локальный сервер, затем в другом терминале:

```bash
npx playwright install chromium webkit
npm run test:browser
npm run audit:routes
npm run audit:secrets
npm run audit:dependencies
```

`audit:routes` использует последнюю сборку из `dist/`. `test:browser` по умолчанию открывает `http://localhost:3000`; другой адрес задаётся через `BASE_URL`. Снимки и результаты проверок записываются в игнорируемую папку `outputs/audit/`. Проверка сигнатур секретов не заменяет аудит всей Git-истории.

## Структура

- `app/` — страницы и маршруты.
- `components/editorial/` — актуальная главная, журнал, витрина и читательские шаблоны.
- `components/about/` — полноэкранная комната «О нас», карточки проектов и подключение жестов.
- `lib/constellation/` — данные проектов, расчёт расположения и отдельный контроллер жестов.
- `components/cart/`, `lib/cart.ts`, `lib/cart-store.ts` — интерфейс, данные и браузерное состояние корзины.
- `components/sketch/` — общие обложки, изображения и медиа, а также предыдущие макеты. Часть этих компонентов используется актуальными страницами.
- `lib/sketch-feature.ts` — пять анонсов Кати и шесть книг витрины.
- `lib/content.ts`, `lib/editorial-texts.json` — ранее перенесённые публикации и каталог.
- `lib/security/` — проверка локальных источников изображений.
- `styles/` — общие правила и стили прежних шаблонов; порядок подключения задан в `app/globals.css`.
- `public/` — изображения, шрифты и другие статические файлы, включая `public/katya/`.
- `content/` — исходные редакционные материалы.
- `docs/` — источники материалов, решения и [аудит кода от 25 ноября](docs/audit/2026-11-25.md).
- `tests/` — проверки страниц, связей и поведения.
- `scripts/` — воспроизводимые проверки браузера, маршрутов и сигнатур секретов.
- `worker/` — серверная точка входа.

В «О нас» на сенсорных устройствах два пальца меняют масштаб карты от 1 до 2,4. После приближения один палец перемещает карту в ограниченных пределах. При возврате к масштабу 1 смещение сбрасывается. Названия сохраняют размер; линии следуют за точками. Тап открывает карточку, жест не вызывает случайный переход. Комната и падающие предметы продолжают двигаться при открытой карточке. На телефонах используются радиальная композиция визитки и отдельная схема для коротких экранов; точки остаются на стене над полом. `lib/constellation/viewport.ts` задаёт общую геометрию дыры и карты, чтобы их пропорции не расходились. Исходники самой визитки не меняются.

## Разработка и публикация

Цельная редакционная композиция находится на `/` и `/preview/editorial`. Предыдущая главная сохранена для сравнения на `/preview/previous`. Решения и проверка описаны в `docs/editorial-study-2026-11-11.md`.

GitHub — основной источник проекта. Изменения сохраняются обычными Git-коммитами и отправляются в этот репозиторий. Не использовать хранилище ChatGPT Sites вместо GitHub.

Публичный сайт пока размещён на действующем хостинге:
https://obratnaya-storona-2.young-mite-9319.chatgpt.site/

Перенос исходников в GitHub не переносит хостинг автоматически. Новый хостинг и домен большого сайта пока не настроены. Существующий сайт продолжает работать до переключения.

`.openai/hosting.json` и `build/sites-vite-plugin.ts` сохранены как совместимость с прежней сборкой; они не требуют доступа к чату для локального запуска. Сборка создаёт `dist/server/index.js` и `dist/client/`. Это серверное приложение, а не готовый статический сайт для GitHub Pages.
