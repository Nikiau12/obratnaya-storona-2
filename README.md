# Обратная сторона — журнал и витрина

Основной репозиторий большого сайта: https://github.com/Nikiau12/obratnaya-storona-2

Это отдельный проект от сайта-визитки `Nikiau12/obratnaya-storona`.
Исходники, изображения, шрифты, контент, тесты и история изменений хранятся здесь.
Для разработки и сборки не нужен ChatGPT или плагин Sites.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm ci
npm run dev
```

## Сборка и проверки

```bash
npm test
npm run start
```

`npm test` собирает приложение и запускает тесты. `npm run start` запускает собранное приложение локально.
Стек: React, TypeScript, Next.js API / vinext, Vite, Cloudflare Workers.

## Структура

- `app/` — страницы и маршруты.
- `components/` — интерфейс; актуальная композиция находится в `components/sketch/`.
- `lib/sketch-feature.ts` — пять анонсов Кати и шесть книг витрины.
- `public/` — изображения, шрифты и другие статические файлы, включая `public/katya/`.
- `content/` — исходные редакционные материалы.
- `docs/katya-static-2026-11-10.md` — источники новых изображений и данных.
- `tests/` — проверки страниц, связей и поведения.
- `worker/` — серверная точка входа.

## Разработка и публикация

Вариант цельной редакционной композиции: `http://localhost:3000/preview/editorial`. Для сравнения текущая главная остаётся на `/`. Решения и проверка описаны в `docs/editorial-study-2026-11-11.md`.

GitHub — основной источник проекта. Изменения сохраняются обычными Git-коммитами и отправляются в этот репозиторий. Не использовать хранилище ChatGPT Sites вместо GitHub.

На 10 ноября 2026 года публичная версия 48 ещё размещена на прежнем хостинге:
https://obratnaya-storona-2.young-mite-9319.chatgpt.site/

Перенос исходников в GitHub не переносит хостинг автоматически. Новый хостинг и домен большого сайта пока не настроены. Существующий сайт продолжает работать до переключения.

`.openai/hosting.json` и `build/sites-vite-plugin.ts` сохранены как совместимость с прежней сборкой; они не требуют доступа к чату для локального запуска. Сборка создаёт `dist/server/index.js` и `dist/client/`. Это серверное приложение, а не готовый статический сайт для GitHub Pages.

Не добавлять стрелки и похожие указатели, подчёркивания, выдуманные тексты, цены и сведения о наличии. Правила интерфейса находятся в `AGENTS.md`.
