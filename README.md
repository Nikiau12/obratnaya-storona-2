# Обратная сторона 2

Первая редакционная версия сайта независимого медиа «Обратная сторона» — о литературе, искусстве и книжных практиках.

## Что уже есть

- главная страница в логике газетной передовицы;
- интерактивные микрорубрики «Слово дня» и «Глаз дня»;
- карточки лонгрида, интервью и короткого материала;
- книжная витрина;
- адаптивная мобильная версия;
- шаблон длинного материала;
- Open Graph-превью для ссылок.

## Локальный запуск

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm test
```

Проект использует Node.js 22+, React, Next.js/vinext и подготовлен для Cloudflare Workers.
