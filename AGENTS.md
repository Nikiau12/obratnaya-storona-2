# Правила проекта «Обратная сторона»

- Никогда и ни при каких обстоятельствах не добавлять стрелки в интерфейс сайта. Правило действует для всех страниц, вариантов дизайна, ссылок, кнопок, меню, логотипов и декоративных элементов.
- Запрет распространяется на символы стрелок, иконки, SVG, изображения и стрелки, нарисованные средствами CSS. Не заменять удалённые стрелки шевронами или другими похожими указателями. Использовать текстовые подписи без стрелок.

## Исходники и публикация

- Основной репозиторий большого сайта: `https://github.com/Nikiau12/obratnaya-storona-2`. Не путать с репозиторием визитки `obratnaya-storona`.
- Сохранять изменения и все используемые ресурсы в GitHub. Не использовать хранилище ChatGPT Sites вместо основного репозитория.
- Пользователь запросил переход от публикации через ChatGPT. Не запускать новую публикацию через Sites по умолчанию. Перенос хостинга выполнять отдельно, на выбранную площадку, сохраняя действующий сайт до проверки нового.
